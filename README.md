# J.J Fashion House Production Starter

Full-stack starter with public storefront, admin login, product add/delete API and persistent JSON data.

Run:
1. Install Node.js.
2. `npm install`
3. Set `ADMIN_USER` and a strong `ADMIN_PASS`.
4. `npm start`
5. Store: `/`
6. Admin: `/admin/login.html`

The password supplied in chat is not embedded in this production starter. Use an environment variable for deployment. For a commercial launch, add HTTPS, hashed passwords/session management, a real database, backups, image storage and payment integration.


## Configured credentials
A local `.env` file has been included for this package. **Do not upload or commit `.env` to a public repository.** Change the password before deploying the store publicly and add `.env` to `.gitignore.
